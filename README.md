# 스탑워치

브라우저에서 바로 실행되는 심플한 스탑워치 웹 앱입니다.

## 실행 방법

`stopwatch.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

## 기능

- **시작 / 정지 / 계속** — 타이머 제어
- **랩 기록** — 구간 시간 및 누적 시간 표시
- **초기화** — 타이머 및 랩 기록 전체 리셋
- 가장 빠른 랩 (초록), 가장 느린 랩 (빨강) 자동 표시
- 1시간 이상 측정 시 시:분:초 형식으로 자동 전환

## 기술 스택

- HTML / CSS / JavaScript (순수 바닐라, 외부 라이브러리 없음)
